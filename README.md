# 🎵 Music Player

A simple and stylish music player built with **HTML, CSS, and JavaScript**.  
It supports play, pause, next, previous, and progress bar control.

## ✨ Features
- Clean UI with album cover and song info
- Play/Pause functionality
- Progress bar with seeking
- Responsive design
- Easy to extend with playlists

## 🚀 How to Run
1. Clone this repository  
2. Place your `.mp3` files in the project folder  
3. Open `index.html` in your browser  
4. Enjoy your music 🎶
